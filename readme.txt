VBall Nation - Tienda Online de Vóley
=====================================

Este proyecto es una tienda online responsive que permite visualizar productos, filtrarlos por categoría, ver detalles, agregarlos al carrito y simular una compra.

---------------------------------------------------
1. ESTRUCTURA DEL PROYECTO
---------------------------------------------------

📁 db/
    - data.json → Contiene el catálogo de productos.

📁 img/
    - Archivos de imagen de los productos y del logo.

📁 Css/
    - style.css → Estilos generales del sitio.

📁 js/
    - app.js → Lógica principal del sitio (clases, renderizado, filtrado, carrito, modales, etc.)

📄 index.html → Página principal de la tienda.

---------------------------------------------------
2. FUNCIONALIDADES PRINCIPALES
---------------------------------------------------

✅ Catálogo de productos paginado.
✅ Filtro por categoría (pelotas, rodilleras, indumentaria).
✅ Modal con detalle de cada producto.
✅ Carrito de compras funcional:
   - Agregar, quitar y modificar cantidades.
   - Visualización con Bootstrap Offcanvas.
   - Guardado en localStorage.
✅ Simulación de pago (formulario en modal).
✅ Confirmación con SweetAlert.
✅ Responsive con Bootstrap 5.
✅ Uso de íconos con Bootstrap Icons.
✅ Animaciones con Animate.css.

---------------------------------------------------
3. TECNOLOGÍAS USADAS
---------------------------------------------------

- HTML5
- CSS3 (con variables y media queries)
- Bootstrap 5.3
- Bootstrap Icons
- JavaScript (clases, eventos, DOM, fetch, localStorage)
- SweetAlert2
- Animate.css

---------------------------------------------------
4. INSTRUCCIONES DE USO
---------------------------------------------------

1. Clonar el repositorio o descargarlo como .zip.
2. Asegurarse de tener todas las imágenes en la carpeta `img/` y el archivo `data.json` en `db/`.
3. Abrir `index.html` con cualquier navegador moderno (no requiere servidor local).

⚠️ El proyecto NO utiliza backend. Toda la lógica corre del lado del cliente.
